## Installing packages 
- I'm using python=3.12
- Create a conda environment using `conda create -n myenvname -c conda-forge`, activate `conda activate myenvname`
- install packages using `pip install -r requirements.txt` or install the packages meantioned in the requirements.txt manually (with `python -m pip install package1 package2 package3`)
- install xarray seperately with `python -m pip install "xarray[complete]"` to include backend dependencies
